# KOHLER AI Bathroom Designer & Planner

An AI-powered, constraint-aware bathroom design assistant that generates personalized KOHLER bathroom product bundles based on bathroom dimensions, budget, preferred design theme, and required fixtures.

The system combines **Hybrid RAG, deterministic constraint validation, bundle optimization, and 2D spatial layout generation** to recommend bathroom product combinations that are relevant to the user's preferences while also considering budget and physical space.

---

## 🚀 Overview

Choosing bathroom products can be difficult because customers need to consider multiple factors simultaneously:

- Bathroom size
- Product dimensions
- Budget
- Design preferences
- Required fixtures
- Installation requirements
- Spatial clearance
- Compatibility between products

The **KOHLER AI Bathroom Designer & Planner** automates this process.

The user provides their bathroom requirements, and the system retrieves relevant KOHLER products, validates them against physical and budget constraints, generates feasible product bundles, ranks the bundles, and produces a 2D bathroom layout.

### Core Pipeline

**Relevant → Allowed → Feasible → Optimal → Explained**

---

## 🎯 Objective

The objective of this project is to build an AI-based bathroom design assistant capable of:

1. Understanding customer requirements.
2. Retrieving relevant KOHLER products.
3. Combining semantic and structured product retrieval.
4. Filtering products according to user constraints.
5. Validating physical bathroom feasibility.
6. Generating optimized product bundles.
7. Providing multiple recommendation options.
8. Generating a 2D bathroom layout.
9. Explaining why a particular design was selected.
